# ClinicFlow MVP — Resume Project

Build a real, working multi-tenant clinic management SaaS (ASP.NET Core +
Angular) as a portfolio/resume project. Scope: Appointments, Patient Records,
Billing (manual), Prescriptions (text-only), basic Reports. 4 roles: Admin,
Doctor, Receptionist, Patient. Shared-DB multi-tenancy via TenantId.
Deploy to Azure free tier.

  - **[BUG FOUND DURING TESTING #1 — CORS]**: adding withCredentials:true to AuthService broke login entirely with a CORS error. Root cause: browsers require the server to explicitly send Access-Control-Allow-Credentials:true whenever a credentialed (cookie-carrying) cross-origin request is made — our CORS policy never had .AllowCredentials(), since no request needed it before today. Fixed by adding .AllowCredentials() to the existing named-origin CORS policy (safe to combine since we never used AllowAnyOrigin() — the browser only forbids credentials + wildcard together).
  - **[BUG FOUND DURING TESTING #2 — SameSite]**: after fixing CORS, login succeeded and the cookie was correctly set (confirmed via Set-Cookie response header), but /auth/refresh still failed with "No refresh token provided" on page reload.
