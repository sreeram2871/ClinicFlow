# ClinicFlow

A multi-tenant clinic management SaaS for solo doctors and small clinics,
built as a portfolio project demonstrating production-oriented engineering
practices (not vibe-coded).

- **Backend:** ASP.NET Core (.NET 8), EF Core, SQL Server, JWT auth
- **Frontend:** Angular
- **Architecture:** Modular Monolith, shared-DB multi-tenancy (TenantId isolation)
- **Deployment:** Azure App Service (free tier) + Azure SQL
